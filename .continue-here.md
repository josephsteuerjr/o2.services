**`HOST-02` is the only remaining engineering row.** Both halves are already measured on the

Put the new spec in `packages/cloudflare/src/`, beside `stop-closes`, in the same lane.

**Five traps, each of which costs more to discover than to read:**

1. **`ANNOUNCE_MULTIADDRS` must be the loopback address** (`--var
   ANNOUNCE_MULTIADDRS:/ip4/127.0.0.1/tcp/<port>/ws`). The tracked `wrangler.jsonc` announces the
   **deployed host** — inherit that value and tab B's circuit dial goes to production. That is the
   hermetic-fixtures rule and the owner's production broken in one move. Apply the `HERMETIC_PROXY`
   pattern too, or the nostr fallback dials out.
2. **Read the drip from `relayService.bytes`, never `traffic.relayed`.** Relayed payload rides
   hop/stop streams on direct legs, so `traffic.relayed` is 0 against this surface **by design** —
   an assertion on it can never redden. The 2026-08-31 figures (310 → 5 007) were
   `relayService.bytes`.
3. **Do not assert `busy < idle` strictly.** The original run happened to see it, but these are two
   noisy keep-alive drips and that assertion is a coin flip. Anchor comparatively inside one run,
   and give it a **positive control first** — assert the counter moved at all during
   reservation/signalling, or you may be comparing two zeros.
4. **Pipe the worker's output, do not `stdio: 'ignore'`.** The enrolment spawn used `ignore`, which
   makes `NoAnnouncedAddressError` unreadable and leaves the refusal inferred from a client-side
   500 — attribution by plausibility, which this repository refuses.
5. **Ports 8841–8844 are free** (swept across the whole tree on 2026-09-14). Taken: 8794, 8801-03,
   8814, 8816, 8818-19, 8831-33, 8835, among others. `O2_IDENTITY_SECRET` must be ≥ 20 characters or
   `/self` answers 500. Own `--persist-to` directory.

**Do not re-touch the deployed relay to confirm any of this.** That run is standing evidence on its
own; the new spec is local-only. And **Phase 32's checkbox stays off regardless** — its criterion 3
is permanently unanswerable, the same shape as phase 29.

## Standing constraints that cost something to relearn

- **The GSD tooling wiped `.planning/STATE.md` for the third time this session** — 440 of 3 353
  lines, body and all, while `state.advance-plan` returned a parse error. Caught by `git diff --stat`
  after the call and reverted. **A tool that reports an error may still have written.** Run
  `git diff --stat` after every `gsd-sdk query state.*` and `roadmap.*` call; `roadmap.update-plan-progress`
  separately flipped Phase 33's checkbox to `[x]` on plan-count grounds against open criteria.
- **A background task's reported exit code is the last command's.** Two red vitest lanes reported
  "exit code 0" because of a trailing `echo`. Grep the captured `LANE EXIT` line out of the task's
  own output file. Same class as `$?` after a pipe; zsh has no `PIPESTATUS`, it is `pipestatus[1]`.
- Commit with explicit paths; `develop` and `main` refuse direct commits; branch prefixes are
  `feature|release|hotfix|bugfix|support|fix|chore|docs|test`.
- Never `git stash` and never `git checkout --` a file you did not write. To learn whether something
  pre-exists, read the base blob: `git show <sha>:<path>`.
- A plant is restored by the **surgical inverse of your own edit**, verified with `cmp` against a
  snapshot taken immediately before planting. The hunk count is a one-way alarm, never the check.
- Run vitest by project; `aot` is its own lane. The `[host conditions]` banner samples before and
  after only, so load arriving mid-run reads as "quiet" — attribute a failure by re-running the file
  alone.
